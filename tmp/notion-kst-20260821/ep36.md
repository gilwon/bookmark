> 프롬프트는 돈 주고 사는 게 아니야. 사놓으면 안 열어보고, 열어봐도 내 업종엔 안 맞아.
>
> 2026년은 프롬프트를 **잘 쓰는 것**보다 **구조를 뜯을 줄 아는 것**이 남는 시대야. AI가 나보다 프롬프트를 잘 쓰거든. 내가 뭘 원하는지 설명만 제대로 하면 돼.
>
> 아래 8개는 프롬프트를 "가져다 쓰는" 데가 아니라 **구조를 뜯어보는 백과사전**으로 쓰는 거야.

## ⚡ 순서부터 — 이대로만 하면 돼

8개를 나열하면 안 쓰게 돼. **순서로 엮어야** 써.

1. **찾기** — [youmind.com](https://youmind.com) 에서 내가 만들고 싶은 결과물 하나 고른다
2. **뜯기** — [prompthero.com](https://prompthero.com) 에서 그게 어떤 칸으로 쪼개졌는지 본다
3. **바꾸기** — [promptflow.tools](https://promptflow.tools) 에 내 업종 단어로 다시 넣는다
4. **굴리기** — 제품이면 [civitai.com](https://civitai.com) 으로 3D 떠서 각도별로 뽑는다

3만 개 저장해도 안 써. **하나 제대로 뜯는 게 빨라.**

## 🔎 헷갈리기 쉬운 것

- **PromptFlow는 같은 이름 사이트가 최소 5개야.** `.tools`가 맞고, `.ai`는 로그인 벽, `.solutions`는 아예 다른 서비스. 8개 중에 여기가 제일 헷갈려
- **YouMind는 `.com`이야.** `.ai`로 들어가면 리다이렉트돼
- **Civitai는 성인 섹션이 있는 플랫폼이야.** 필터 확인하고 써. 3D(PolyGen)는 2026년 7월에 들어온 기능이고 매일 주는 무료 크레딧으로 돌려볼 수 있어
- **PromptCreek은 프롬프트 1,298개 + 에이전트 스킬 1,246개.** 모델별 숫자(ChatGPT 989 등)는 태그라서 중복 집계야. 스킬은 전부 무료지만 프롬프트 번들은 따로 유료로 팔아
