## 프롬프트 & 대화 설계 (01–25)
	**01. 목표 1문장 먼저** — 첫 줄에 “원하는 결과는 OOO”부터 적으면 답이 산으로 안 간다
	```plain text
원하는 결과: [한 문장으로]
그다음에 요청: [무엇을 해줘]
	```
	**02. 맥락 한 줄 붙이기** — 누가·왜·어디에 쓰는지만 적어도 답의 결이 달라진다
	```plain text
맥락: 이 결과는 [누가] [왜] [어디에] 쓸 겁니다.
요청: [무엇을 해줘]
	```
	**03. 역할 지정** — “너는 마케팅 담당자야”처럼 주면 관점이 그쪽으로 고정된다
	```plain text
너는 [10년 차 마케팅 담당자]야. 그 관점에서 [무엇을] 해줘.
	```
	**04. 출력 형식 고정** — 표·목록·JSON 중 하나로 잠그면 다시 손볼 일이 줄어든다
	```plain text
출력 형식: [표 / 번호 목록 / JSON] 하나로만.
표라면 열 이름: [열1, 열2, 열3]
	```
	**05. 톤은 형용사로** — 격식·친근·간결 한 단어면 원하는 말투로 나온다
	```plain text
톤: [격식 / 친근 / 간결] 하게.
[요청 내용]
	```
	**06. 분량은 숫자로** — “3줄” “500자 내”처럼 못 박아야 그 길이를 지킨다
	```plain text
분량: [3줄 / 500자 내 / 항목 5개].
[요청 내용]
	```
	**07. 독자 지정** — 초보용인지 임원 보고용인지 밝히면 난이도가 맞춰진다
	```plain text
독자: [처음 보는 사람 / 실무 담당자 / 임원 보고용].
그 눈높이로 [요청 내용]
	```
	**08. 금지사항 먼저** — 하지 말 것을 앞에 적으면 엉뚱한 방향이 처음부터 차단된다
	```plain text
하지 말 것: [영어 섞지 말기 / 추측하지 말기 / 표 쓰지 말기]
요청: [내용]
	```
	**09. 좋은 예시 1개** — “이런 느낌” 샘플 하나면 결과가 그쪽으로 정렬된다
	```plain text
이런 느낌으로 써줘:
"""
[좋은 예시 붙여넣기]
"""
요청: [내용]
	```
	**10. 나쁜 예시 1개** — 싫은 스타일도 하나 주면 지뢰를 미리 제거한 답이 온다
	```plain text
이런 스타일은 피해줘:
"""
[싫은 예시 붙여넣기]
"""
요청: [내용]
	```
	**11. 큰 일은 쪼개기** — 작은 프롬프트 여러 개로 나눠야 빠지는 부분 없이 끝난다
	```plain text
이 일을 작은 단계로 쪼개서 목록으로 먼저 보여줘.
내가 확인하면 1단계부터 하나씩 진행하자.
일: [큰 요청]
	```
	**12. 중요한 조건은 앞에** — 지시는 맨 앞, 긴 자료는 맨 뒤에 붙여야 지시가 안 묻힌다
	```plain text
[가장 중요한 조건 1줄]
[요청]

참고 자료:
"""
[긴 자료]
"""
	```
	**13. 여러 안 받기** — “3가지 방향으로 줘”라고 하면 첫 답에 갇히지 않는다
	```plain text
[요청]을 서로 다른 방향 3가지로 만들어줘.
각각 한 줄로 어떤 방향인지 먼저 적고 시작해.
	```
	**14. 대화로 다듬기** — 첫 답 보고 고쳐 말하는 게 완벽한 한 문장보다 빠르다
	```plain text
(첫 답을 받은 뒤)
[2번]은 좋아. 다만 [이 부분]을 [이렇게] 바꿔서 다시 줘.
	```
	**15. 먼저 질문 받기** — “필요한 정보 3개만 물어봐”라고 하면 AI가 먼저 되묻는다
	```plain text
시작하기 전에, 이 일을 잘하기 위해 나한테 물어봐야 할 것 3개만 먼저 질문해줘.
일: [요청]
	```
	**16. 단계 나눠 시키기** — 초안→개선→최종으로 나누면 한 번에 시킬 때보다 좋아진다
	```plain text
3단계로 가자.
1) 초안 2) 초안의 약점 3개 찾아 개선 3) 최종본
각 단계 끝나면 멈추고 보여줘.
일: [요청]
	```
	**17. 구분선 쓰기** — ### 나 따옴표로 지시와 자료를 나누면 섞여서 헷갈리지 않는다
	```plain text
### 지시
[무엇을 해줘]

### 자료
[붙여넣기]

### 출력 형식
[형식]
	```
	**18. 자료는 인용 감싸기** — 긴 원문은 “””로 감싸야 지시문과 따로 인식된다
	```plain text
아래 원문을 요약해줘. 원문은 """ 안에만 있어.
"""
[긴 원문]
"""
	```
	**19. 판단 기준 선언** — 정확성·가독성·속도 중 우선순위를 말하면 그 기준으로 답한다
	```plain text
우선순위: 정확성 > 가독성 > 속도.
확실하지 않은 건 '확인 필요'라고 표시해.
[요청]
	```
	**20. 문장 길이 제한** — “각 항목 1줄, 20자 내”로 정하면 장황해지지 않는다
	```plain text
각 항목은 1줄, 20자 이내로.
[요청]
	```
	**21. “단계별로 생각해” 빼기** — 생각하는 모델엔 목표만 줘도 알아서 추론한다
	```plain text
(생각하는 모델 선택 후)
목표: [무엇을 달성]
제약: [조건]
결과만 보여줘.
	```
	**22. 자기 검수 붙이기** — 오탈자·누락·모순을 스스로 점검하게 하면 검수까지 끝난다
	```plain text
다 쓴 뒤에 오탈자·빠진 항목·앞뒤 모순이 있는지 스스로 점검하고,
고친 부분을 맨 아래에 목록으로 적어줘.
[요청]
	```
	**23. 근거 요구** — “왜 그런지 이유도 같이”를 붙이면 근거 없는 답이 걸러진다
	```plain text
[요청]
각 결론마다 왜 그렇게 판단했는지 이유를 한 줄씩 붙여줘.
	```
	**24. 마무리 형식 고정** — 요약 3줄 + 다음 행동 3개로 끝내면 받자마자 바로 쓴다
	```plain text
[요청]
마지막은 항상: 요약 3줄 + 다음 행동 3개.
	```
	**25. 프롬프트 템플릿화** — \[목표\]\[자료\]\[조건\]\[형식\] 빈칸 서식이면 매번 채우기만 하면 된다
	```plain text
[목표]
[자료]
[조건]
[형식]

↑ 이 서식을 저장해 두고 매번 대괄호만 채워서 보내기
	```
## 파일·이미지 & 앱 연동 (26–50)
	**26. PDF 핵심만 추출** — 요약 말고 결론·근거·리스크·액션만 뽑게 하면 쓸모가 다르다
	```plain text
(PDF 첨부 후)
이 문서에서 요약 말고 이것만 뽑아줘:
1) 결론 2) 결론의 근거 3) 리스크 4) 우리가 할 행동
	```
	**27. 긴 문서는 목차 먼저** — 구조부터 잡고 필요한 장만 파고들면 시간이 절반으로 준다
	```plain text
(긴 문서 첨부 후)
먼저 목차만 뽑아줘. 그다음 내가 고르는 장만 자세히 읽자.
	```
	**28. 여러 파일 비교** — 두 문서를 올리고 차이점만 표로 달라 하면 비교가 한 번에 끝난다
	```plain text
(파일 2개 첨부 후)
두 문서의 차이점만 표로. 열: 항목 / A 문서 / B 문서 / 비고
	```
	**29. 스샷 관찰 범위 지정** — “표·버튼·오류코드만 봐줘”로 좁혀야 정확해진다
	```plain text
(스크린샷 첨부 후)
이 화면에서 [표 / 버튼 / 오류 코드]만 봐줘. 나머지는 무시.
	```
	**30. 이미지 영역 지정** — “왼쪽 상단 빨간 박스”처럼 위치를 짚으면 그 부분만 읽는다
	```plain text
(이미지 첨부 후)
왼쪽 상단 빨간 박스 안에 뭐라고 적혀 있는지 그대로 옮겨줘.
	```
	**31. 전후 스샷 비교** — 2장 올리고 달라진 점만 물으면 변화가 바로 정리된다
	```plain text
(스크린샷 2장 첨부 후)
첫 번째가 전, 두 번째가 후야. 달라진 점만 목록으로.
	```
	**32. 스샷 → 표 재구성** — 화면 캡처를 복붙 가능한 표로 바꾸면 손으로 옮길 일이 없다
	```plain text
(화면 캡처 첨부 후)
이 화면 내용을 복사해서 쓸 수 있는 표로 바꿔줘.
	```
	**33. 차트는 해석 질문** — “이 그래프의 핵심 3개는?”이라 해야 숫자 나열이 아니다
	```plain text
(차트 첨부 후)
이 그래프에서 핵심 3개는 뭐야? 숫자 나열 말고 해석으로.
	```
	**34. 엑셀·CSV 분석** — 이상치와 반복 패턴부터 찾게 하면 분석 방향이 잡힌다
	```plain text
(엑셀·CSV 첨부 후)
이상치(튀는 값)와 반복되는 패턴부터 찾아줘. 그다음 어디를 더 볼지 제안해.
	```
	**35. 차트 그려 달라기** — “이 데이터로 차트 그려줘”면 코드를 돌려 그래프까지 준다
	```plain text
(데이터 첨부 후)
[열 이름] 기준으로 [막대 / 선] 차트 그려줘. 제목과 축 이름 포함.
	```
	**36. 정리 규칙 먼저** — 중복·결측·형식 통일 기준을 정해주면 데이터 정리가 한 번에 끝난다
	```plain text
(데이터 첨부 후)
정리 기준: 중복 제거 / 빈칸은 '없음' / 날짜는 YYYY-MM-DD.
이 기준으로 정리한 표를 줘.
	```
	**37. 긴 글은 첨부로** — 길게 붙여넣으면 자동으로 첨부가 돼 대화창이 안 지저분해진다
	어디서 켜나: `긴 글을 붙여넣으면 자동으로 첨부 파일로 바뀜`
	```plain text
(붙여넣은 뒤)
첨부한 글을 [요약 / 교정 / 번역]해줘.
	```
	**38. 파일 라이브러리** — 올린 파일·이미지가 한곳에 모여 다음 대화에서도 다시 쓴다
	어디서 켜나: `왼쪽 사이드바 → 라이브러리`
	```plain text
라이브러리에 있는 [파일 이름] 다시 열어서 [요청].
	```
	**39. 이미지 생성** — 용도·스타일·비율까지 문장에 넣어야 원하는 그림이 나온다
	```plain text
이미지 생성해줘.
용도: [인스타 표지] / 스타일: [3D 렌더, 파스텔] / 비율: [4:5]
내용: [무엇이 어떻게]
글자는 넣지 마.
	```
	**40. 이미지 부분 수정** — “배경만 노을로 바꿔줘”처럼 말하면 일부만 수정된다
	```plain text
(생성된 이미지에 이어서)
배경만 노을로 바꿔줘. 나머지는 그대로.
	```
	**41. 생각하는 이미지** — 복잡한 그림은 이 옵션을 켜면 계획을 세운 뒤 그린다
	어디서 켜나: `이미지 생성 시 '생각하는 이미지' 옵션`
	```plain text
복잡한 구성이야. 먼저 구도를 계획한 다음 그려줘: [내용]
	```
	**42. Google Drive 연결** — 앱을 연결하면 드라이브 문서를 대화에서 바로 찾고 요약한다
	어디서 켜나: `플러그인 디렉토리 → Google Drive 연결`
	```plain text
드라이브에서 [파일 이름 일부] 찾아서 핵심만 요약해줘.
	```
	**43. Gmail·캘린더 연결** — 메일 정리와 일정 조율을 채팅으로 처리하게 된다
	어디서 켜나: `플러그인 디렉토리 → Gmail · Google Calendar 연결`
	```plain text
오늘 회신 필요한 메일만 골라 보낸 사람·요지·마감을 표로.
이번 주 빈 시간 찾아서 [상대]와 미팅 후보 3개 제안해.
	```
	**44. Drive를 라이브러리에** — 드라이브 파일이 뜨니까 다운로드 없이 바로 첨부한다
	어디서 켜나: `라이브러리 → Google Drive 탭`
	```plain text
라이브러리에서 드라이브 파일 [이름] 첨부해서 [요청].
	```
	**45. Notion·Slack 연결** — 회사 자료를 찾아 대화에 그대로 끌어오게 된다
	어디서 켜나: `플러그인 디렉토리 → Notion / Slack 연결`
	```plain text
노션에서 [페이지 이름] 찾아서 이 대화에 가져와 줘.
	```
	**46. 앱 권한은 ‘중요 행동만’** — 읽기는 자동, 발송·삭제만 물어보게 설정된다
	어디서 켜나: `설정 → 앱 → 권한 요청: '중요 행동만 확인'`
	```plain text
(설정만 하면 됨 — 읽기는 자동, 발송·삭제 전엔 물어봄)
	```
	**47. Excel·시트 애드인** — 시트 안에서 수식과 정리를 바로 시킬 수 있다
	어디서 켜나: `Excel · Google Sheets 애드인 설치`
	```plain text
(시트 안에서) 이 열의 값을 기준으로 [정리 / 수식] 만들어줘.
	```
	**48. PowerPoint 애드인** — 장표 안에서 문구와 구조를 바로 다듬게 된다
	어디서 켜나: `PowerPoint 애드인 설치`
	```plain text
(장표 안에서) 이 슬라이드 문구를 [간결하게 / 임원용으로] 다듬어줘.
	```
	**49. 구글 계정 여러 개** — 개인·회사 계정을 따로 연결해 자료를 나눠 관리한다
	어디서 켜나: `설정 → 앱 → Google 계정 추가`
	```plain text
(개인·회사 계정을 각각 연결해 두면 됨)
	```
	**50. 플러그인 디렉토리** — 앱·스킬 묶음을 한 번에 골라 설치할 수 있다
	어디서 켜나: `플러그인 디렉토리`
	```plain text
(앱·스킬 묶음을 한 번에 설치. 필요한 것부터 1~2개)
	```
## 리서치 & 학습 (51–75)
	**51. 웹 검색 켜기** — 최신 정보는 검색을 켜고 물어야 출처 붙은 답을 받는다
	어디서 켜나: `입력창 → 웹 검색 켜기`
	```plain text
[주제] 최신 정보 찾아줘. 출처 링크 꼭 붙여.
	```
