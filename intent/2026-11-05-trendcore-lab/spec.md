# Spec: 트렌드코어 스킬공유자료실 메뉴
Source: intent.md (Status: draft)

요청문이 열린 질문을 이미 닫아서 draft 상태 그대로 명세를 적는다.

## Requirements
1. 사이드바 프롬프트 섹션에 메뉴 하나가 추가된다. 라벨은 스킬공유자료실, 경로는 /trendcore-lab 이다. 신영선 자료실 다음에 둔다. 명령 팔레트에도 같은 목적지가 있다.
2. 목록은 https://www.trendcore.co.kr/lab 의 고유 `/guide/` 카드를 모두 담는다. 2026-11-05에 받은 HTML 기준 74개다. 기초첫걸음(`/guide/first-steps`)을 포함한다. 화면의 "전체 73" 숫자로 하나를 빼지 않는다.
3. 각 항목은 제목, 한 줄 설명, 번호 또는 배지 라벨, 분류, 날짜, 원문 주소를 가진다. 분류는 꿀팁, 정보, 기초첫걸음, 가이드 중 하나다.
4. 날짜에 연도가 없으면 2026으로 둔다. 카드의 월·일이 9월에서 11월이다.
5. 목록 기본 정렬은 날짜 최신순이다. 같은 날이면 원문 카드 순서를 유지한다.
6. 검색은 제목, 설명, 번호, 분류, 태그에 걸린다. 분류 필터와 최신순·오래된순이 있다.
7. 상세 화면은 제목, 분류, 날짜, 본문, 원문 링크를 보여 준다. 본문은 단계, 프롬프트, 이미지, PDF·외부 링크를 포함한다.
8. 본문에서 빼는 것. 오픈카카오 링크, "SNS자동화 시스템 무료강의", 목록으로 돌아가는 상단 막대, 목차, 하단 풋터, 스크립트, 추적 쿼리.
9. 상대 경로 이미지와 파일은 `https://www.trendcore.co.kr` 기준 절대 주소가 된다.
10. 기초첫걸음처럼 `div.body`가 없는 글은 본문 섹션을 읽고, 스크립트가 채우는 빈 프롬프트는 기본값(관심 분야 맛집, 주제 미선택)으로 채운다. 페이지 스크립트는 실행하지 않는다.
11. 하단 탭은 5개 그대로다. Pages `custom_pages`와 Prompts에는 쓰지 않는다. 기존 김스듴·심팀장·신영선 데이터는 바꾸지 않는다.

## Design
정적 JSON 카탈로그와 마크다운 본문. 조회·검색·정렬 함수, 목록 페이지, 상세 페이지, 추출 스크립트, 테스트. 상세 본문은 기존 가이드 본문 렌더러를 재사용한다. 화면 톤은 김스듴 가이드 목록과 같다. 카드, 배지, 검색, 빈 상태, 포커스 링, 호버 테두리를 그대로 쓴다. 새 색과 새 레이아웃은 만들지 않는다.

데이터 필드. slug, title, summary, number, category, tags, publishedAt, sourceUrl. tags에는 NEW, 지금 인기, 단계 수, 소요 시간처럼 날짜·분류를 뺀 카드 꼬리표가 들어간다.

## Decisions
- 메뉴 이름과 경로. 사이트 목록 제목이 스킬공유자료실이다. 경로는 기존 `/sdk-guides` 형태를 따라 `/trendcore-lab`으로 한다.
- 카드 74개. 필터 칩의 73은 기초첫걸음을 뺀 수로 본다. 사용자는 목록 내용을 모두 넣으라고 했다.
- 연도 2026. 정보 글 본문에 "2026년 9월 3일"이 있고, 카드는 그해 9월에서 11월이다.
- 정렬. 김스듴 가이드와 같이 날짜 최신순, 같은 날은 저장 순서. 저장 순서는 랩 페이지의 카드 순서다.
- 메뉴 위치. 기존 순서 단언을 깨지 않도록 신영선 자료실 뒤에 둔다.
- 프롬프트. 페이지 스크립트를 실행하지 않고, 빈 pre에 대입된 템플릿 문자열만 읽는다. 주제 기본값은 맛집이다.

## Conflicts
없음.

## Acceptance
- 로그인 후 사이드바에서 스킬공유자료실을 열어 74건이 보인다.
- 최신순에서 11월 4일 글이 9월 글보다 앞이고, 같은 11월 4일에서는 074가 073보다 앞이다.
- `/trendcore-lab/074` 본문에 업리카 주소, 절대 경로 이미지, PDF 링크가 있고 오픈카카오 문구는 없다.
- `/trendcore-lab/first-steps`에 절대 경로 이미지와 기본 프롬프트 문장이 있다.
- `/trendcore-lab/i005`는 분류가 정보이고 외부 기사 링크가 있다.
- 하단 탭은 5개다.
