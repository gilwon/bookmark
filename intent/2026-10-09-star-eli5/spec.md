# Spec: Star 다섯 살 설명
Source: intent.md (Status: draft)

## Requirements
1. 로그인한 사용자가 등록된 Star 상세를 열면, 큰 그림과 짧은 말이 있는 HTML 문서가 그 화면 안에 보인다.
2. 같은 문서를 그 Star의 HTML 주소로 열면 `text/html` 화면이 나온다.
3. 화면은 뭐예요, 설치, 사용, 장단점 네 칸이다. 예전 한 줄 소개 화면은 쓰지 않는다.
4. 뭐예요는 저장된 설명이다. 한글 문단이 있으면 그 문단만 쓰고, 두 문장을 넘기지 않는다. 한 문장이 120자를 넘으면 120자 안에서 끊고 말줄임표를 붙인다.
5. 설치, 사용, 장단점은 저장된 README에서만 가져온다. 한글 README가 있으면 그 글을 먼저 본다. 제목으로 설치, 사용, 좋은 점, 아쉬운 점을 구분한다. 글에 없는 장단점이나 설치 방법은 없다고 적고, 레포가 하는 일을 추측하지 않는다. README를 아직 가져오지 않았으면 그 칸은 아직 가져오지 않았다고 적는다.
6. 레포 이름과 설명은 HTML로 이스케이프한다. 문서에 `script` 요소가 없다.
7. 링크는 `http`와 `https`만 허용한다. 다른 사용자의 Star 주소는 404다. 로그인하지 않으면 문서를 주지 않는다.
8. 기존 설명 필드와 README는 수정하지 않는다. 새 데이터베이스 컬럼은 만들지 않는다.

## Design
저장돼 있는 레포 이름, 설명, 주소로 HTML 문서를 만든다. 그림은 이름과 설명의 단어로 고른 인라인 SVG다. 장면은 영상, 디자인, 대화, 터미널, 데이터, AI, 문서, 코드, 별 순서다. 영어 단어는 토큰이 같을 때만 맞추고, 한글은 포함 여부로 맞춘다. 한 글자 한글은 다른 단어 안에 섞이므로 쓰지 않는다. 디자인 한글 단서는 디자인, 색상, 폰트, 레이아웃이다. 데이터 한글 단서는 데이터, 분석, 차트다.

상세 페이지는 이 문서를 iframe으로 넣고, 같은 문서를 새 탭으로 여는 링크를 둔다. HTML 응답은 세션과 소유권을 확인한 뒤 반환한다. 프레임은 같은 출처만 허용하고, 문서의 CSP는 인라인 스타일 외의 리소스를 막는다.

## Decisions
- 대상은 등록된 Star 전부다. 사용자가 오늘 분만 한정하지 않았다.
- 말의 출처는 저장된 설명과 README다. 더 쉬운 문장으로 다시 쓰면 사실이 바뀔 수 있어, 문장은 줄이기만 한다.
- 사용자가 기존 다섯 살 설명을 지우고 소개, 사용, 설치, 장단점을 다시 넣으라고 했다. 저장해 둔 다섯 살 설명 행은 없고, 화면을 네 칸으로 바꿔 다시 만든다.
- 컬럼을 추가하지 않는다. 화면은 설명을 바꿀 때마다 다시 만들어진다.
- intent는 draft다. 사용자는 구현을 요청했고, 열린 질문은 없었다.

## Conflicts
없음.

## Acceptance
- 설명이 있는 Star 상세에 다섯 살 설명 iframe이 있고, HTML 주소가 같은 그림을 반환한다.
- 영어 다음 빈 줄 다음 한글인 설명은 한글만 본문으로 쓴다.
- 빈 설명, 스크립트 문자열, 다른 사용자 조회가 요구사항 5·6·7을 지킨다.
- 기존 설명과 README 저장 경로는 그대로다.
