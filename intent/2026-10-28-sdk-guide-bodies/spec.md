# Spec: 김스듴 가이드 본문
Source: intent.md (Status: draft)

## Requirements
1. `/sdk-guides/<slug>`를 열면 해당 가이드의 본문이 화면에 보인다.
2. 본문에는 문단, 제목, 목록, 표, 인용, 코드 블록, 프롬프트, 본문 안의 링크가 유지된다.
3. 본문 이미지가 있으면 주소가 `https`인 이미지로 보이고, 가로를 넘지 않는다.
4. 메일 받기, 대기자 카드, 팀 도입 문의, 다음 글, 목차, 개인정보 동의, 추적 쿼리는 본문에 없다.
5. 목록 71건의 슬러그·제목·분류·도구·태그·발행일·출처 주소는 바뀌지 않는다.
6. 목록에 없는 슬러그 상세는 계속 404다.
7. 글 아래에 원문 사이트로 가는 링크가 남는다.
8. Pages `custom_pages`와 Prompts 표는 읽지도 쓰지도 않는다.

## Design
목록 JSON과 본문 저장을 분리한다. 상세 서버 화면이 슬러그의 본문 마크다운을 읽고, 클라이언트에서 기존 README 렌더와 같은 방식으로 HTML로 정화해 보여 준다. 본문은 원본 `div.guide-detail-body`만 가져온다. 그 안의 장식 선택자가 있으면 제거한다. 코드 블록의 줄 단위 span은 줄바꿈이 있는 텍스트로 펼친 뒤 마크다운으로 바꾼다.

## Decisions
- 대상은 로컬 목록 71건이다. 2026-10-28 원본 `/guides/`, `/guides/2/`, `/guides/3/`의 슬러그와 순서가 같다. 새 글을 목록에 더하지 않는다.
- 장식은 선택자로 제거한다. `30일`이라는 말 자체를 본문에서 지우지 않는다. 대기자 카드가 남으면 `개인정보 수집`, `도입 상담 요청`, `챌린지 오픈 알림`으로 걸러진다.
- 이미지는 data URL로 넣지 않는다. 절대 `https` 주소로 둔다. 이번 표본 글에는 본문 이미지가 없었다.
- 발행일 줄 `2026. 10. 27.` 형태는 순서 목록으로 잘리지 않게 폭 없는 문자를 앞에 둔다.
- intent Status는 draft다. 사용자가 본문을 넣으라고 요청했으므로 그 범위로 진행한다.

## Conflicts
없음.

## Acceptance
- 71개 슬러그마다 비어 있지 않은 본문이 있다.
- `mcp-vs-api-docs-claude-code` 본문에 `7.4배`, `claude mcp list`, 앤트로픽 연구 글 주소가 있고 코드 펜스가 3개다.
- 같은 본문에 `개인정보 수집`, `도입 상담 요청`, `android-tv-ads-cleanup`, `utm_source`가 없다.
- 상세 화면에서 그 문장과 코드 블록이 보이고, 원문 링크가 새 탭으로 열린다.
- 목록 검색·필터·71건 개수는 그대로다.
