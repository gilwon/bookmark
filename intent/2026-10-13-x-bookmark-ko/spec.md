# Spec: X 북마크 한글 번역

## 요구
- 번역 표는 `src/data/x-bookmark-text-ko.json`이다. 키는 게시 ID다.
- 본문에 한글이 있으면 번역을 붙이지 않는다.
- 한글이 없고 표에 있으면 원문 뒤에 빈 줄과 한국어를 저장한다.
- 화면은 원문을 기존처럼 여섯 줄까지 보여주고, 번역은 그 아래에서 잘리지 않게 보여 준다.
- 검색은 번역 문장도 포함한다.
- 동기화는 API 본문을 저장할 때 같은 표를 다시 적용한다. API 본문이 한글이면 표를 무시한다.
- 표에 없는 게시와 이미 한글인 게시는 본문만 둔다.

## 완료
- 운영 `x_bookmarks`에서 한글이 없고 표에 있는 행은 원문과 한국어가 함께 있다.
- 같은 백필을 다시 실행하면 갱신 건수가 0이다.
- `node --test --import tsx tests/x-bookmarks.test.mjs`가 통과한다.
