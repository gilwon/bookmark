# Spec: 신영선 자료 아카이브 메뉴

## 메뉴
- 경로 `/yeongseon-archive`.
- 사이드바 라벨 `신영선 자료실`. 프롬프트 섹션, 심팀장 자료실 다음.
- 커맨드 팔레트에도 같은 라벨과 경로를 둔다.
- 하단 탭 배열 길이는 그대로 5다.

## 목록 데이터
- 출처 HTML의 `const ITEMS` 412건. id는 고유하다.
- 첫 항목 id `405d86104de280f59105df276560229a`, 제목 `클로드코드 유명 명령 8개 끝 vs 미래 판정표`.
- 마지막 항목 id `1a9d86104de281ae8525c34501d2d500`, 제목 `멍청한 GPT, 5초만에 천재로 만드는 방법`, 공개일 `2025-03-01`.
- 출처 수는 신영선 311, 에이나우 101이다. 과정은 기본 과정 370, 심화 과정 42다.
- 글 주소는 `https://yeongseon.kr/archive/{id}.html`이다.
- 카드에 보이는 값은 공개일, 출처, 과정, 제목, 요약, 주제다. 주제는 ` · `로 잇는다.
- 메타 줄은 `공개일 · 출처 · 과정`이다. 원문과 같다.

## 거르기
- 검색어는 공백으로 나누고, 제목·요약·과정·주제에 모두 포함될 때만 남긴다. 대소문자는 가리지 않는다. 검색어는 160자까지다.
- 출처 버튼은 전체, 그다음 출처 이름을 가나다순. 개수를 붙인다.
- 주제 버튼은 현재 출처 안에서 개수가 많은 주제 10개다. 선택된 주제가 10개 밖이면 그 주제도 버튼에 남긴다.
- 출처를 바꾸면 주제 선택은 풀린다.
- 한 번에 24편을 보이고, 더 보기는 24편씩 추가한다. 남은 편수를 버튼에 적는다.
- 건수 문구는 결과가 있으면 `{전체}편 중 {보이는 수}편 보는 중`, 없으면 `검색 결과 0편`이다.
- 검색이나 필터가 있으면 초기화 버튼을 보인다.
- 쿼리 `q`, `source`, `topic`, `shown`을 주소에 남긴다. `shown`은 24보다 클 때만 남긴다.

## 빈 결과
- 제목 `검색 결과가 없습니다.`
- 설명 `다른 검색어를 입력하거나 검색·필터를 초기화해 주세요.`
- 초기화 버튼이 있다.

## 완료
- 단위 테스트가 412건, 첫·끝 항목, 출처 수, 검색·출처·주제 거르기, 24편 단위를 확인한다.
- 화면에서 첫 카드와 더 보기, 출처 필터가 동작한다.
